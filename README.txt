LOREN AI - versión local gratuita

IMPORTANTE:
- Este proyecto usa Ollama, que ejecuta un modelo de IA en tu propia computadora.
- No necesita una API paga.
- GitHub Pages por sí solo NO puede ejecutar este servidor ni la IA.
- Para que otras personas usen tu IA por internet, más adelante hará falta alojar el servidor en un servicio compatible.

PARA PROBAR EN TU PC:
1. Instalá Node.js desde https://nodejs.org
2. Instalá Ollama desde https://ollama.com
3. Abrí una terminal y ejecutá: ollama run llama3.2
   La primera vez descarga el modelo y puede tardar.
4. Extraé esta carpeta.
5. Abrí una terminal dentro de la carpeta y ejecutá: npm install
6. Ejecutá: npm start
7. Abrí en el navegador: http://localhost:3000

No compartas claves privadas ni contraseñas.
